Why did it crash?

Digdown watches your Docker apps. When one fails, it tells you why in plain words, and it can fix it.

Free, open source, and on your own machine.

Try the demoor install it

What happens when something breaks

  1. Noticesevery 15 seconds
  2. Reads the logsand the container state
  3. Finds the causewith an AI that can only read
  4. Double-checks itagainst the evidence
  5. Fixes itif you allow it
  6. Undoes itif the fix didn't hold

You choose how far it goes

  1. Explain onlySays why. Changes nothing.
  2. Suggest fixesSays what to do. You do it.
  3. Fix after I approveFixes it when you click.
  4. Auto healFixes it by itself, within limits.

Start at the top. What auto heal fixes, and its limits.

Works with any app in Docker

No plugins. It works from what Docker reports.

Auto heal fixes it by itself It comes to you

  • Crashed or restartingRestarts it, or starts what it needs
  • Out of memoryRaises the limit and restarts it
  • Health check failingRestarts it
  • Stopped, but neededStarts it
  • Near its memory limitRaises the limit
  • Site erroring or slowRestarts it, checks again
  • Disk fullClears unused images, if you allow it
  • Wrong setting, secret or bugTells you what to change (this one comes to you)
  • Stopped on purpose, or a finished jobLeaves it alone (this one comes to you)

Does anything need you? The most urgent problem comes first. How to read the dashboard.

Good to know

  • The AI can be wrong. That's why auto heal starts off.
  • Docker and Compose only. No Kubernetes.
  • Only need restarts? Docker's restart policy or docker-autoheal is enough.
  • Private logs? Use a local AI. A hosted one sees names in your logs.

Run it

With Docker

Just Docker. About a minute.

docker run -d --name digdown --restart unless-stopped \
  -p 127.0.0.1:8088:8088 \
  -v /var/run/docker.sock:/var/run/docker.sock -v digdown-data:/data \
  --add-host host.docker.internal:host-gateway \
  ghcr.io/aishwaryawambule/digdown:latest
docker logs digdown    # prints a link that signs you in

Open the link it prints, and answer three questions. Step by step.

Without Docker

Python 3.11 or newer, Node 22 or newer, Git, and Docker on the same computer.

git clone https://github.com/aishwaryawambule/digdown.git && cd digdown
python3 -m venv .venv && . .venv/bin/activate
scripts/build-dashboard.sh && pip install .
digdown start

Open localhost:8088 and answer three questions. Step by step.
